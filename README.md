# Being right isn't enough to win — Verification registry

This repository is the **material proof** behind the book *Being right isn't enough to win* (Frédéric Briet). It holds the digital signatures (sha256) of every tested hypothesis, the key figures of each study, and the laboratory code inventory, so any reader can check that the numbers in the book are real and that no rule was adjusted after looking at the data.

I'm not asking you to trust me. I'm giving you what you need to check me.

🇪🇸 Versión en español más abajo · *Spanish version below.*

## What you'll find here

- **`SELLOS.md`** — the list of digital signatures for each study, with its date. Each signature is a unique sha256 code computed **before looking at the data**. If the study had been modified afterwards, the signature would not match.
- **`RESULTADOS.md`** — the key figures of each hypothesis (what was measured, what came out, what the verdict was), exactly as they appear in the book.
- **`COMO_VERIFICAR.md`** — a plain-language guide to what each thing proves, no programming required.
- **`Lab code inventory.pdf`** — the laboratory code inventory: how many lines were written, in which languages and markets. It separates the code that stayed working (45,856 lines) from the total trial-and-error effort (285,498 lines of Python across 815 scripts), with each row marked as exact or estimate.

## The idea in one sentence

A person with decades in the markets, trained up to Oxford, put the most disciplined artificial intelligence to work for months, across three markets, hunting for the rule that wins. The result: no deployable rule that won repeatedly after costs. This repository is the proof, number by number, that behind that conclusion there is real, measured work — not an opinion.

# Acertar no basta para ganar — Registro de verificación

Este repositorio es la **prueba material** del libro *Acertar no basta para ganar* (Frédéric Briet). Contiene las firmas digitales (sha256) de cada hipótesis probada, las cifras clave de cada estudio y el inventario del código del laboratorio, para que cualquier lector pueda comprobar que los números del libro son reales y que ninguna regla se ajustó después de mirar los datos.

No te pido que me creas. Te doy con qué comprobarme.

## Qué encontrarás aquí

- **`SELLOS.md`** — la lista de firmas digitales de cada estudio, con su fecha. Cada firma es un código sha256 único que se calculó **antes de mirar los datos**.
- **`RESULTADOS.md`** — las cifras clave de cada hipótesis (qué se midió, qué salió, cuál fue el veredicto), tal como aparecen en el libro.
- **`COMO_VERIFICAR.md`** — guía sencilla para entender qué prueba cada cosa, sin necesidad de saber programar.
- **`Lab code inventory.pdf`** — el inventario del código del laboratorio: separa el código que quedó funcionando (45.856 líneas) del esfuerzo total de prueba y error (285.498 líneas de Python en 815 scripts).

## La idea en una frase

Una persona con décadas en los mercados, formada hasta en Oxford, puso a la inteligencia artificial más disciplinada a buscar durante meses, en tres mercados, la regla que gana. El resultado: cero regla desplegable que ganara de forma repetida después de costes. Este repositorio es la prueba, número a número, de que detrás de esa conclusión hay trabajo real y medido —no una opinión.
